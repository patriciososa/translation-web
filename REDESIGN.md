# Visual Redesign Specification
## Translation Services Website

## Objective

Redesign the existing website **without changing its structure, content hierarchy, or user flows**.

The current sitemap, page layout, navigation, and content organization have already been validated and should remain intact.

This project is a **visual modernization**, not an information architecture redesign.

---

# Your Role

Act as an award-winning Visual Designer, UI Designer, Brand Designer, Motion Designer, and Front-End Design Engineer.

Use **ui-ux-pro-max-skill** for all design decisions.

Think like the design teams behind Stripe, Linear, Vercel, Notion, Framer, and Webflow.

---

# Critical Constraints

DO NOT:

- Change page hierarchy
- Reorganize sections
- Rewrite content
- Remove sections
- Add unnecessary sections
- Change business logic
- Modify navigation structure
- Alter user journeys
- Redesign the site's architecture

Instead:

Improve the visual experience while respecting the existing website.
